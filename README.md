# hunter-exam-trainer
A Progressive Web App (PWA) for practicing the Swedish Hunter Exam theory test.

---

## Project Overview

The Hunter Exam Trainer is a web and mobile application designed to help students prepare for the Swedish Hunter Theory Examination (Jägarexamen).

The application allows users to:

- Practice questions by subject
- Take random quizzes
- Simulate the official 70-question theory exam
- Track progress and statistics
- Review previous results

The application will be developed as a Progressive Web App (PWA), allowing it to run on desktop, tablet, and mobile devices.

---

## Project Objectives

- Build a responsive PWA
- Support all eleven theory subjects
- Provide multiple practice modes
- Display user statistics and progress
- Include an admin interface for question management
