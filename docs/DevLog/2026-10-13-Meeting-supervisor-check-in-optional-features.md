# Meeting: Supervisor check-in with Klas, optional features

- **Date:** 2026-10-13, 10:00
- **Attendees:** Klas Åkerskog, Fadi Alaraj, Md Abdus Sikdar, Maja Blom, Hans Malmefjäll

## Topics discussed

The team presented what has been done since 2026-09-30 (login and accounts,
statistics, the admin area, automated tests), gave a short live demo and an
estimate of progress: the MVP features are nearly complete. Then the group
asked Klas the questions below and went through the list of optional features
(see [2026-10-12 decision](2026-10-12-Decision-optional-features-list.md)).

1. **User testing weeks 44–45:** Klas is working on it. Either a group of
   students or only course leaders will test the app.
2. **Google login:** not in the Project Plan; the previous team started it, and
   it is in the app but switched off. To work for real it needs a Google Cloud
   account (ideally owned by Allez) and the final web address. Klas will ask
   Allez whether they want it.
3. **Number of exam questions (Project Plan: 150–200):** the target can be
   ignored, since admins can now add questions.
4. **Q-006 (statistics per student or per group):** answered through the
   features below: per-student statistics are fine, with search by student or
   subject, and students choosing which results to share; a group view needs
   grouping by course ("if we have time").
5. **GDPR:** how long may the app store students' information? Klas will
   research it.

## Optional features: Klas's priorities

| Priority | Features |
|---|---|
| Yes, high priority | Students choose which of their results to share with course leaders |
| Yes | Report a question (students flag errors; shown to admins) |
| Good, if we have time | Archive questions; practise weak areas; explanation after each answer; species identification (birds first, they are hardest for students) |

| Not answered (ask again) | Payment or course booking; practical parts (shooting test, search test) |

## Decisions made

1. Drop the 150–200 question target; remove it from the project documents so it
   isn't mentioned again.
2. Before the 2026-10-15 group meeting, an AI estimates the time needed for each
   optional feature, so the group can use it to plan.
