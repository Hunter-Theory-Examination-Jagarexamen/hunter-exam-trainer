# Meeting: Which optional features become issues

- **Date:** 2026-10-19, 14:00
- **Attendees:** Fadi Alaraj, Md Abdus Sikdar, Maja Blom, Hans Malmefjäll

## Topics discussed

Each group member had read the list of optional features before the meeting
(as decided at the [2026-10-15 meeting](2026-10-15-Meeting-project-plan-and-work-order.md)).
The group discussed how to choose which features to turn into issues, using
Klas's priorities from the [2026-10-13 meeting](2026-10-13-Meeting-supervisor-check-in-optional-features.md)
and his answers of [2026-10-16](2026-10-16-Decision-supervisor-answers.md).

## Decisions made

1. Klas's priority values decide which optional features are turned into
   issues, and in what order.
2. The native app (App Store / Google Play) is dropped, even though Klas
   first called it "big priority if we have time". Klas confirmed on
   2026-10-16 that it is not worth the maintenance cost.

## Follow-up work

- Create issues for the optional features, in order of Klas's priorities.
